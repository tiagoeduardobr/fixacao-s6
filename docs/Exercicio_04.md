# Exercício 2 — A câmera de selfie

## expo-camera · 25 minutos

1. Instale a dependência:

   ```bash
   npx expo install expo-camera
   ```

2. Implemente os 3 estados da permissão:
   - Carregando.
   - Botão "Liberar câmera".
   - Câmera.

3. Adicione uma `CameraView` de tela cheia, começando com a câmera frontal.

4. Sobre a câmera, na parte inferior, adicione:
   - Um botão redondo de disparo para tirar a foto.
   - Um botão para alternar entre as câmeras frontal e traseira.

5. Após tirar a foto:
   - Exiba a imagem com uma borda verde.
   - Mostre o botão "Tirar outra".

## Desafio extra

Guarde as 3 últimas fotos e exiba-as em uma `FlatList` horizontal de miniaturas.
